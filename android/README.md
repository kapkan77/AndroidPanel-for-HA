# Киоск Android — предварительная версия 1.3.0

Приложение не содержит адреса дома, паролей HA или готового PIN.
При первом запуске укажите полный адрес нужного представления дашборда,
задайте PIN из 4 цифр и войдите в HA отдельным пользователем панели.

Начиная с версии 1.3.0 адрес и настройку полного киоска можно передать из HA:
**Конструктор → Android-панель → Проверить подключение → Установить**.
Тогда адрес при первом запуске уже заполнен, а PIN и вход в HA выполняются на панели.
[Подробная инструкция мастера и список команд](../docs/android-setup.md).

## Установка и автозапуск

Это тестовая сборка: установка выполняется через Android Debug Bridge
с параметром `-t`. В архиве нет инструментов Android SDK — используются
официальные Android Platform Tools.

```text
adb install -t hmi-kiosk.apk
adb shell am start -n local.home.hmi/.MainActivity
```

После первой настройки приложение можно выбрать домашним экраном Android.
Для полноценной защиты от выхода приложение должно стать владельцем
**выделенного** устройства (Device Owner). Обычная установка APK такой защиты
не даёт. На устройстве с уже существующими учётными записями Android может
не разрешить назначение владельца. Не сбрасывайте личный телефон ради теста.

```text
adb shell dpm set-device-owner local.home.hmi/.PanelAdmin
```

Затем в служебном меню панели включите **Защиту от детей**.
Приложение назначит себя домашним экраном и включит блокировку выхода.
После перезагрузки домашний экран открывается автоматически; дополнительно
есть обработчик завершения загрузки Android. Ограничения фонового запуска
зависят от прошивки, поэтому после настройки требуется проверка перезагрузкой.

## Доступ и восстановление

- Вход в служебное меню — шестерёнка и PIN. Периоды без повторного запроса:
  каждый раз, 30 секунд, 1, 5 или 10 минут.
- Аварийный вход при недоступности HA: пять касаний в левом верхнем углу,
  затем PIN. Здесь доступны адрес панели, обновление, Android и выход.
- PIN хранится в закрытых данных приложения как PBKDF2-SHA256 с солью.
  Он не является кодом сигнализации HA.
- «Выйти из киоска» отключает защиту и возвращает системный домашний экран.
  Чтобы снова закрепить панель и восстановить автозапуск, включите защиту.
- До окончания тестирования оставьте возможность подключения по ADB.

Тестовая сборка имеет `testOnly=true`: это оставляет возможность восстановления
через ADB. При необходимости снять владельца с **этого тестового приложения**:

```text
adb shell dpm remove-active-admin local.home.hmi/.PanelAdmin
```

## Обновление существующих панелей

До перехода со старой локальной версии откройте аварийное меню → **Адрес панели**
и сохраните текущий адрес. Старые сборки могли брать его из исходного кода,
а новая версия читает только сохранённую настройку.
Обновление `adb install -t -r` тем же ключом подписи сохраняет данные приложения,
включая вход в HA и PIN. Другой ключ не подходит для обновления поверх установленной
копии; приватный ключ подписи в пакет не включён.

## Сборка

Исходники и проект для Android Studio находятся здесь же. Нужны JDK 17,
Android SDK 35, Android Gradle Plugin 8.7.3 и Gradle 8.9. Gradle wrapper пока
не включён; используйте установленный Gradle или Android Studio.

```text
gradle :app:assembleDebug
```

Этот путь сборки подготовлен, но пока не проверен в Android Studio. Готовый APK
локального выпуска собран и проверен отдельным сборочным инструментом.
Для публикации понадобится собственный постоянный ключ подписи, отдельная
проверка выпуска и решение о переходе с тестовой сборки на обычную.

Пока испытана Android 11 / WebView 144. Android 8–10 и другие прошивки требуют
проверки; устаревший WebView может не поддерживать используемые стили карточки.
