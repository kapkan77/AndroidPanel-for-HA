# Проверки выпуска 0.3.0

Предварительный выпуск интеграции Home Panel, APK 1.3.0.

| Проверка | Результат |
|---|---|
| Новый шаблон, очистка привязок, часовой пояс HA, единицы датчиков, экраны и меню | 23 браузерные проверки |
| Отмена и возврат действий | 30 браузерных проверок |
| Шестерёнка и редактируемое служебное меню | 17 браузерных проверок |
| Мастер Android, разделение проверки/установки, отсутствие передачи PIN, права в интерфейсе | 13 браузерных проверок |
| Нажатия при обновлениях, клавиатура, касание, свайп, заставка | 21 браузерная проверка; 120/120 удерживаемых нажатий |
| Шесть оформлений, контраст, размеры, книжная ориентация, история | 46 браузерных проверок |
| Формат WebSocket-команд через настоящий декоратор HA 2026.11.2 и probatio 0.13.0 | 14 проверок |
| Серверная часть, конфигурационная форма, шаблоны и установки Android на имитации устройства | 28 локальных тестов Python |
| Политика PIN | 28 Java-проверок предыдущей версии; класс не менялся |
| Проверка URL | 18 Java-проверок предыдущей версии; класс не менялся |
| APK 1.3.0 | Сборка, подпись v2/v3, номер версии, SDK и наличие ProvisionReceiver проверены |
| Защита получателя конфигурации Android | Манифест требует android.permission.DUMP |
| Инструкция | HTML с 17 главами; проверена ширина 1920/480 |

Сценарии установки на имитации Android включают смену устройства за IP, чужого
владельца, несовместимую подпись, старый Android, истёкшую проверку, другую учётную
запись HA, пропадание возможности сохранить список устройств и защиту URL от
выполнения дополнительных команд. Пользователь без прав администратора не может
вызвать установку на сервере. PIN в API не принимается.

Киоск 1.2.0 ранее проверялся на настоящей панели Android 11: вход в HA, защита выхода,
четырёхзначный PIN и автозапуск после перезагрузки работали. Это не подтверждает
новый сценарий установки APK 1.3.0 из HA — его требуется проверить отдельно.

**Проверено пользователем:** интеграция 0.2.0 установлена через Маркетплейс,
конструктор открыт и сущности назначены. В 0.3.0 исправлены обнаруженные ошибки
нажатий и схемы WebSocket-команд. Эти исправления и полный мастер после
заводского сброса Android ещё требуют подтверждения на настоящем устройстве. Рабочий HA и Android ради проверки новой версии
автоматически не изменялись. Состояние проверок GitHub смотрите во вкладке Actions;
само наличие файла workflow не означает успешного прохождения проверок.

Проверка HACS Action настроена на структуру пользовательского репозитория.
Проверки `license`, `description`, `topics` явно отложены: лицензия пока не выбрана,
метаданные общего каталога не оформлены. Это не означает прохождения полной
валидации каталога и не является заявкой в общий каталог.
