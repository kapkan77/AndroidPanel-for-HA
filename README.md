# Home Panel

Конструктор настенных панелей Home Assistant с бесплатным приложением киоска Android.
Предварительная версия **0.2.0**. Проверенный размер экрана — **480×480**.


В готовых шаблонах сущности не назначены.

- Свободная сетка: перетаскивание, изменение размеров, значков, шрифтов и цветов.
- Шаблон «Климат и комфорт»: термостат, влажность, CO₂, VOC, ночник и увлажнитель.
- Шаблон «Пустая панель» для собственного интерфейса.
- Дополнительные экраны со свайпами и отдельные меню с кнопками перехода.
- Редактируемое служебное меню, отмена/возврат действий, импорт/экспорт макетов.
- Ночные часы, дата и температура; отдельная яркость основного и ночного экрана.
- Киоск Android: автозапуск, защита выхода PIN из 4 цифр, собственная цифровая клавиатура.
- Мастер установки Android по IP из конструктора: проверка ADB, установка APK и настройка киоска.

## Что произойдёт после установки интеграции

Интеграция подключит карточку и её редактор. Она не сканирует сеть и не меняет
Android автоматически. В конструкторе кнопка **Android-панель** открывает мастер.
Проверка ADB и установка доступны только администратору HA; сервер проверяет права.

После ввода IP кнопка **Проверить подключение** читает сведения об устройстве.
Отдельная кнопка **Установить приложение и киоск** копирует локальный APK, устанавливает
его с сохранением данных, по выбранному флажку назначает владельца устройства,
передаёт адрес дашборда и запускает приложение. PIN и вход в HA выполняются на Android.
После создания PIN киоск назначает себя домашним экраном для автозапуска и включает
защиту выхода. Мастер не выполняет сброс, удаление аккаунтов, очистку приложения,
смену PIN, обход сертификатов или перезагрузку устройств.

Этот новый мастер пока испытан на имитации Android. Первая полная проверка на
чистой панели выполняется пользователем; выпуск экспериментальный.

## Установка через маркетплейс

Для текущей предварительной версии требуется Home Assistant **2026.11 или новее**.
В этой версии HA маркетплейс находится в **Настройки → Маркетплейс**.
Проект пока не включён в общий каталог: его нужно добавить по ссылке.

1. Откройте **Настройки → Маркетплейс**.
2. Если потребуется, самостоятельно прочитайте и примите предупреждение о сторонних
   проектах и подключите GitHub.
3. Выберите **Добавить по ссылке** (в старом интерфейсе HACS — «Пользовательские репозитории»).
4. Укажите `https://github.com/kapkan77/AndroidPanel-for-HA`, тип — **Интеграция**.
5. Откройте **Home Panel**, установите нужную версию и перезапустите HA.
6. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Home Panel**.
7. Обновите страницу браузера. Добавьте на дашборд карточку **Панель комнаты**.

Интеграция сама подключает модуль карточки. Добавлять ресурс JavaScript вручную не нужно.
Путь установки через маркетплейс подготовлен; испытание на восстановленном HA
выполняется пользователем. Автоматические проверки публикации видны во вкладке Actions.

## Создать первую панель

1. Создайте отдельный дашборд или представление с типом **Панель (одна карточка)**.
2. Добавьте карточку **Панель комнаты** и нажмите **Открыть конструктор**.
3. Слева в разделе **Шаблоны** выберите **Климат и комфорт** или **Пустая панель**.
4. Нажмите **Применить шаблон**. Устройства в шаблонах не назначены.
5. Выберите каждый элемент и справа укажите его устройство или датчик.
6. В **Настройках экрана** отдельно выберите температуру для ночной заставки.
7. Нажмите **Применить макет**, затем **Сохранить** в редакторе карточки HA.

Если карточка не появилась в списке, добавьте её вручную:

```yaml
type: custom:hmi-room-panel
room: Новая комната
```

Полный пример дашборда: [`examples/dashboard.yaml`](examples/dashboard.yaml).
Готовый макет без сущностей: [`templates/climate-comfort.json`](templates/climate-comfort.json).
Его также можно загрузить кнопкой **Загрузить макет** в конструкторе.

## Несколько комнат

Одной интеграции достаточно для всего дома. Для комнат с разными устройствами
создавайте отдельные карточки или представления. На каждой Android-панели открывайте
адрес нужного представления. В одной карточке можно добавить до 9 дополнительных
экранов или меню. Обычные экраны переключаются свайпами; меню открываются кнопками.

Через **Скачать макет / Загрузить макет** можно переносить собственное оформление.
Такой экспорт сохраняет выбранные сущности: после переноса в другой дом их нужно
заменить. Встроенные шаблоны в этом репозитории всегда поставляются без сущностей.
Применение встроенного шаблона заменяет макет и очищает привязки; действие можно отменить.

## Приложение Android

[Исходники, APK и инструкция](android/README.md) находятся в папке `android`.
Киоск устанавливается отдельно от интеграции HA. При первом запуске задаются адрес
дашборда, собственный PIN из 4 цифр и вход в HA обычной формой авторизации.
Для настоящей блокировки выхода требуется режим владельца выделенного устройства.

Сам конструктор работает также в браузере и приложении HA. Управление яркостью,
защищённый выход и локальный PIN доступны в приложении киоска. PIN хранится на
устройстве; он не входит в макет и не является кодом сигнализации HA.

## Обновление со старой локальной карточки

Сначала сохраните макет и резервную копию старого ресурса. После установки интеграции
и её включения удалите **только прежний ресурс `hmi-room-panel`** из ресурсов
дашбордов. Иначе браузер может первым загрузить старую копию.
Перезагрузите интерфейс всех панелей. Уже сохранённые карточки
`custom:hmi-room-panel` совместимы; повторно выбирать устройства в них не требуется.

## Состояние и ограничения

- Карточка и киоск испытаны на Android 11, WebView 144, экране 480×480.
  Логический макет пока квадратный; другие пропорции требуют доработки.
- Интерфейс конструктора пока русский; экран добавления интеграции — RU/EN.
- APK требует минимум Android 8, но Android 8–10 ещё не испытаны.
- Яркость задаётся двумя уровнями. Автоматическая регулировка по датчику пока недоступна.
- Элемент сигнализации требует существующую сущность `alarm_control_panel`;
  он не создаёт охранную систему. Код проверяет сама сигнализация HA.
- Серверная часть проверена локальными тестами с подменой API HA. Чистую установку
  из маркетплейса ещё предстоит испытать; это предварительный выпуск.
